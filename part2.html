Parte 2: La Superautopista de los Datos

2.1. SATA, PCIe y NVMe

Podemos comparar el almacenamiento con una carretera. SATA es una vía con menos capacidad de transferencia; PCIe permite enlaces más rápidos. NVMe es el protocolo que muchos SSD utilizan sobre PCIe. M.2 describe un formato físico: un SSD M.2 puede usar SATA o PCIe, según el modelo y la placa.[16], [17], [18]

🛣️ SATA

Vía con menos capacidad

~213-560 MB/s

La imagen de una carretera de dos carriles ayuda a entender la diferencia, pero no describe literalmente todos los conectores. En IA, un disco SATA puede funcionar para aprender inferencia local, aunque la carga del modelo sea más lenta.[16], [17]

🚀 PCIe con NVMe

Vía con más capacidad

~3500-12400 MB/s

Muchos SSD NVMe M.2 usan cuatro líneas PCIe, llamadas x4. Además, un SSD PCIe 4.0 no alcanza siempre la misma velocidad que otro: importan el controlador, la memoria y la capacidad del modelo.[18], [19]

En IA, un disco más rápido puede reducir el tiempo de lectura de modelos y datasets. Sin embargo, después de cargar el modelo en RAM o VRAM, la velocidad de generación puede depender principalmente de CPU, GPU y memoria. Un SSD SATA no hace imposible aprender inferencia local.

2.3. Un cálculo teórico de transferencia

Para un archivo de 16 GB decimales, uso 16 000 MB y la fórmula tiempo = tamaño / velocidad.

Con SSD SATA (560 MB/s)

16 000 MB / 560 MB/s = 28,6 segundos (ideal)

Con NVMe PCIe 4.0 (3500 MB/s)

16 000 MB / 3500 MB/s = 4,6 segundos (ideal)

Esta diferencia ayuda a entender el papel del SSD, pero no es el tiempo real de inicio de un modelo. El tiempo real también incluye abrir archivos, preparar memoria, procesar el formato y transferir datos a la GPU. La velocidad puede cambiar con la temperatura, la caché y el espacio libre del SSD. Para medir el inicio de un modelo habría que utilizar el mismo archivo, equipo y programa, y repetir la prueba.

✓ Observación: Este cálculo es teórico. No representa una medición propia ni garantiza tiempos reales de carga de modelos.

2.4. PCIe 5.0 y DirectStorage

PCIe 5.0

PCIe 5.0 duplica la tasa de transferencia por línea frente a PCIe 4.0. Esto permite SSD con mayor velocidad secuencial, como el T700 de 2 TB de la tabla. La mejora resulta útil cuando la aplicación mueve muchos datos y el almacenamiento es realmente el límite. No elimina todos los tiempos de espera.[19]

DirectStorage

DirectStorage es una API de Microsoft. La versión 1.1 incorpora descompresión en GPU para aplicaciones compatibles. La aplicación debe integrar esta tecnología. No basta con instalar un SSD NVMe para que todos los programas de IA la utilicen.[21]

Tampoco es correcto dibujar siempre una ruta SSD → VRAM que elimina toda intervención de CPU y RAM. La documentación de DirectStorage 1.1 describe una ruta que puede utilizar memoria del sistema antes de la descompresión en GPU. En este trabajo no dispongo de una prueba de DirectStorage con Llama 70B; por eso no atribuyo a esta API una reducción concreta del tiempo de auditoría.[21]

2.5. Tecnologías experimentales y nuevas conexiones

CXL (Compute Express Link)

CXL es una tecnología de interconexión entre procesadores, memoria y aceleradores. Puede permitir expansión y agrupación de memoria en sistemas compatibles. No es un nuevo material de almacenamiento ni convierte automáticamente la RAM adicional en VRAM de una tarjeta doméstica.[22]

Almacenamiento óptico 5D

El almacenamiento óptico 5D investigado en la Universidad de Southampton utiliza estructuras dentro de vidrio de sílice. Es una línea de investigación orientada al archivo duradero. La universidad describe capacidades potenciales de hasta 360 TB para determinados formatos. No equivale a un SSD comercial ni ofrece capacidad o velocidad ilimitadas. Además, el vidrio de sílice contiene silicio: se trata de una alternativa al almacenamiento electrónico convencional, no de la desaparición del elemento químico.[23]

PCIe 6.0

PCIe 6.0 especifica 64 GT/s por línea. GT/s significa transferencias por segundo y no debe confundirse con GB/s. El valor de 256 GB/s se refiere al ancho de banda agregado en ambas direcciones de un enlace x16. No es la velocidad de un SSD M.2 x4. No uso este estándar para prometer una velocidad futura concreta de la computadora propuesta.[24]
